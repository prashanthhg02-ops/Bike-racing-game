# Neon Rider

A lightweight, browser-based bike racing game. Dodge traffic and oil slicks, build your distance, and beat your personal best.

## Play

Open `index.html` in a modern web browser. No installation or build step is required.

## Controls

- **← / →** or **A / D** — steer between lanes
- **W** or **↑** — boost
- **Enter** or **Space** — start or restart
- On touchscreens, use the on-screen arrow buttons to steer

Your best distance is saved in the browser. Use the music-note button to toggle crash sound effects.
